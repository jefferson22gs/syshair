## 1. Primeiro Acesso e Registro

### Passo 1: Criar Conta

1. **Acesse o site:** 
   - Instale o PWA no seu celular (clique em "Adicionar à Tela Inicial")
   - Ou acesse via navegador: `https://seu-dominio.com`

2. **Cadastrar novata conta:**
   - Clique em "Cadastrar" no header
   - Preencha:
     - Nome completo
     - Email
     - Senha (mínimo 8 caracteres)
     - Telefone (opcional)
   - Clique em "Criar conta"

3. **Verificação:**
   - Confirme seu email (verifique sua caixa de entrada)
   - Faça login com suas credenciais

### Passo 2: Ativar 7 Dias de Teste GRATIS

1. **Durante o fluxo de registro:**
   - Você será direcionado automaticamente para o período de teste
   - 7 dias completos de acesso a TODAS funcionalidades

2. **Benefícios do trial:**
   - ✅ Profissionais ilimitados
   - ✅ Agendamentos ilimitados
   - ✅ Todos os recursos ativos
   - ✅ Suporte prioritário via WhatsApp

3. **Após 7 dias:**
   - Você será notificado antes do fim do trial
   - Aparecerá um banner avisando que o trial está acabando
   - Assine por apenas R$ 39,90/mês para continuar

## 2. Configuração Inicial do Salão

### Passo 1: Cadastro Básico

1. **Após login, vá em:**
   - Menu lateral **"Configurações"**
   - **"Informações do Salão"**

2. **Preencha os dados:**
   - **Nome do Salão:** Ex: "Barbearia do João"
   - **Nome Empresarial:** Ex: "João da Silva ME"
   - **CNPJ:** (Opcional - para emissão de notas)
   - **Email institucional:** Ex: contato@barbeariadasjoao.com
   - **Telefone principal:** (com DDD, com 55) Ex: 5511999998888
   - **WhatsApp:** (O mesmo formato) Ex: 5511999998888
   - **Endereço completo:**
     - Rua, número, bairro
     - Cidade
     - Estado
     - CEP
   - **Descrição do salão:** Texto marketing que aparecerá na página pública
   - **Horário de funcionamento:**
     - Abertura: Ex: 08:00
     - Fechamento: Ex: 19:00
   - **Dias de funcionamento:**
     - Segunda a Sábado (selecione os dias)
   - **Upload de logo:** Clique e escolha a imagem do logo

3. **Clique em "Salvar"**

### Passo 2: Personalização Visual

1. **Ainda em Configurações:**
   - **"Aparência"**
   - Escolha a **cor principal** do sistema
   - Opções: Gold (padrão), Rose, Emerald, Purple, Blue, Coral
   - Isso muda toda a identidade visual do seu sistema

2. **Slug da página pública:**
   - Configure um URL personalizado
   - Ex: "barbeariadasjoao"
   - Sua página será: `/agendar/barbeariadasjoao`

3. **Clique em "Salvar"**

## 3. Cadastro de Profissionais e Serviços

### Passo 1: Cadastrar Serviços

1. **Vá para menu:**
   - **"Serviços"** no menu lateral

2. **Clique em "+ Adicionar Serviço"**

3. **Preencha:**
   - **Nome do serviço:** Ex: "Corte Cabelo Masculino"
   - **Descrição:** Ex: "Corte com lavagem e finalização"
   - **Preço:** Ex: 50.00
   - **Duração (minutos):** Ex: 45
   - **Categoria:** (opcional) Para organização
   - **Icone:** Escolha um ícone visual
   - **Foto:** Upload de imagem (opcional)

4. **Clique em "Salvar"**

5. **Repita para todos os serviços:**
   - Barba
   - Coloração
   - Tratamentos
   - Peles
   - Etc.

### Passo 2: Cadastrar Profissionais

1. **Vá para menu:**
   - **"Profissionais"** no menu lateral

2. **Clique em "+ Adicionar Profissional"**

3. **Preencha:**
   - **Nome completo:** Ex: "Carlos Silva"
   - **Bio/Descrição:** Ex: "Especialista em cortes modernos"
   - **Especialidade:** Ex: "Cortes Masculinos"
   - **Email:** (Opcional)
   - **Telefone:** (Opcional)
   - **Taxa de comissão:** Ex: 30 (vira 30% do valor)
   - **Upload de foto:** Foto do profissional
   - **Dias de trabalho:** Selecione quais dias atende
   - **Horário:** Configure horário específico (se diferente do salão)
   - **Autônomo?** Marque se for autônomo (recebe pagamento direto)
   - **Perfil público?** Marque se quer que apareça na página pública

4. **Vincular serviços:**
   - Use o slider para selecionar quais serviços este profissional realiza
   - Pode customizar preço e duração por profissional

5. **Clique em "Salvar"**

## 4. Como Usar o Dashboard

### Visão Geral do Dashboard Principal

1. **Acesse:**
   - Menu **"Dashboard"**

2. **Métricas principais (topo):**
   - **Agendamentos Hoje:** Quantidade de agendamentos marcados para hoje
   - **Faturamento Mensal:** Total arrecadado no mês corrente
   - **Clientes Ativos:** Total de clientes cadastrados
   - **Taxa de Ocupação:** Percentual de horários ocupados vs disponíveis

3. **Agenda do dia (central):**
   - Lista de todos os agendamentos do dia
   - Mostra:
     - Horário
     - Nome do cliente
     - Profissional
     - Serviço
     - Status (Pendente/Confirmado/Realizado/Cancelado)
   - Cada agendamento pode ser:
     - Confirmado (muda status para "Confirmado")
     - Cancelado (muda status para "Cancelado")
     - Marcado como realizado (muda status para "Completed")

4. **Próximos agendamentos:**
   - Lista dos próximos 7 dias
   - Visualização rápida da agenda futura

5. **Profissionais disponíveis agora:**
   - Quem está online e pode atender

## 5. Gerenciamento de Agendamentos

### Criar Novo Agendamento Manualmente

1. **Vá para:**
   - **"Agendamentos"** no menu lateral

2. **Clique em "+ Novo Agendamento"**

3. **Passo 1: Cliente**
   - **Buscar cliente existente:** (ou criar novo)
     - Digite nome ou telefone
     - Selecione da lista
   - **Novo cliente:**
     - Clique em "Criar novo cliente"
     - Preencha: Nome, Telefone, Email

4. **Passo 2: Serviço**
   - Selecione o serviço desejado
   - Veja preço e duração

5. **Passo 3: Profissional**
   - Selecione o profissional desejado
   - Veja especialidade e rating

6. **Passo 4: Data e Horário**
   - Escolha o dia no calendário
   - Escolha o horário na grade
   - Verde = disponível, Vermelho = ocupado

7. **Passo 5: Confirmação**
   - Revisar todos os dados
   - Adicionar observações (opcional)
   - **Enviar WhatsApp:** Marque para enviar confirmação via WhatsApp
   - Clique em "Confirmar Agendamento"

### Editar ou Cancelar Agendamento

1. **Na lista de agendamentos:**
   - Clique nos 3 pontos (...) do agendamento
   - Escolha uma opção:
     - **Editar:** Modificar data, hora, profissional, etc.
     - **Cancelar:** Cancelar o agendamento
       - Pode confirmar envio de WhatsApp ao cliente
       - Motivo (opcional)

### Ver Agenda em Calendário

1. **Na tela de Agendamentos:**
   - Use a vista de calendário
   - Navegue entre meses
   - Clique em qualquer dia para ver os agendamentos
   - Filtre por profissional, status, cliente

## 6. Gestão de Clientes (CRM)

### Cadastrar Novo Cliente

1. **Vá para:**
   - **"Clientes"** no menu lateral

2. **Clique em "+ Adicionar Cliente"**

3. **Preencha:**
   - **Nome completo:** Obrigatório
   - **Email:** (Opcional)
   - **Telefone:** (Opcional)
   - **Data de aniversário:** (para envio de promoções)
   - **Observações:** Notas sobre o cliente (preferências, alergias, etc.)
   - **Preferências:**
     - Profissional favorito
     - Serviços preferidos
     - Horários preferidos
     - Forma de pagamento

4. **Clique em "Salvar"**

### Visualizar Histórico do Cliente

1. **Na lista de clientes:**
   - Clique no nome do cliente

2. **Você verá:**
   - **Dados pessoais** (pode editar)
   - **Histórico de agendamentos:**
     - Todos agendamentos passados
     - Serviços realizados
     - Profissionais que atendeu
     - Valor total gasto
   - **Métricas:**
     - Total de visitas
     - Última visita
     - Média gastos por visita
     - Recorrência (frequência)
   - **Programa de fidelidade:**
     - Pontos acumulados
     - Nível atual (Bronze/Prata/Ouro/Diamante/VIP)
     - Próximo nível

### Editar Dados do Cliente

1. **Na tela do cliente:**
   - Clique em "Editar"
   - Modifique qualquer informação
   - Clique em "Salvar"

### Excluir Cliente

1. **Na lista de clientes:**
   - Clique nos 3 pontos (...)
   - Clique em "Excluir"
   - ⚠️ **Cuidado:** Isso apagará todo o histórico

## 7. Controle Financeiro

### Métricas Financeiras no Dashboard

1. **No menu lateral:**
   - **"Financeiro"**

2. **Visão geral:**
   - **Receita hoje:** Total faturado hoje
   - **Receita este mês:** Total do mês corrente
   - **Meta mensal:** Comparação com meta (se definida)
   - **Receita por profissional:** Ranking de quem mais faturou

3. **Gráficos:**
   - **Faturamento diário:**
     - Últimos 30 dias
     - Comparação com mês anterior
     - Visual em linha ou barras

   - **Faturamento por serviço:**
     - Quais serviços mais vendem
     - Ticket médio por tipo

   - **Faturamento por profissional:**
     - Cada profissional com seu faturamento
     - Taxa de comissão calculada

### Recebimentos e Pagamentos

1. **Na aba "Transações":**
   - Lista de todas transações
   - Filtros:
     - Período
     - Profissional (recebimento)
     - Cliente
     - Status: Pendente/Pago/Cancelado

2. **Marcar como recebido:**
   - Acesse um agendamento
   - Mude status para "Completed"
   - Sistema cria recebimento automaticamente

3. **Pagar comissão a profissional autônomo:**
   - Na lista de transações
   - Cada profissional autônomo aparece
   - Ver valor a receber
   - Status do pagamento

### Relatórios Financeiros

1. **Clique em "Exportar relatório":**
   - Escolha período
   - Selecione tipo:
     - Receita geral
     - Por profissional
     - Por serviço
   - Formato: Excel (.xlsx) ou PDF
   - Clique em "Gerar"

2. **Ler o relatório:**
   - Abra no Excel
   - Ver detalhamento completo
   - Use para controlar contas

## 8. Recursos Avançados

### BI & Inteligência Artificial

1. **Acesse:**
   - **"Recursos Avançados"** → **"BI & IA"**

2. **O que você verá:**

   **A) Previsão de Faturamento:**
   - Gráfico com projeção dos próximos 6 meses
   - Baseado em histórico de dados
   - Mostra tendência de crescimento ou queda
   
   **B) Risco de Churn:**
   - Lista de clientes em risco de não voltar
   - Categorizado por risco:
     - 🟢 Baixo (retorna regularmente)
     - 🟡 Médio (atrasou 1-2 semanas)
     - 🔴 Alto (atrasou 3+ semanas)
   - Ações sugeridas:
     - Enviar promoção
     - Ligar/WhatsApp
     - Oferecer desconto na próxima visita

   **C) Cross-Sell Inteligente:**
   - Por cliente, sugere serviços adicionais que ele pode gostar
   - Baseado em histórico de visitas
   - Ex: "Este cliente sempre faz corte, sugira adicionar barba"

   **D) Insights do Salão:**
   - Sugestões automáticas
   - Ex: "Você tem muitos agendamentos vazios após 17h nas terças"
   - Ex: "Profissional João está sobrecarregado nas manhãs"

### Sistema de Fidelidade

1. **Acesse:**
   - **"Recursos Avançados"** → **"Fidelidade"**

2. **Como funciona:**

   **A) Pontuação automática:**
   - Cada agendamento realizado = pontos
   - Valor do serviço em reais = pontos (ex: R$50 = 50 pontos)
   - Bônus emdias especiais

   **B) Níveis:**
   - 🥉 **Bronze:** 0 - 499 pontos (começa aqui)
   - 🥈 **Prata:** 500 - 999 pontos (2% bônus em pontos)
   - 🥇 **Ouro:** 1.000 - 4.999 pontos (5% bônus em pontos)
   - 💎 **Diamante:** 5.000 - 14.999 pontos (10% bônus em pontos)
   - 👑 **VIP:** 15.000+ pontos (15% bônus em pontos + descontos exclusivos)

   **C) Badges Colecionáveis:**
   - "Primeira visita" - ✓ (automático)
   - "Fiel mensal" - visitou todo mês por 6 meses
   - "Big spender" - gastou R$1.000+
   - E mais...

   **D) Resgatar pontos:**
   - Cliente pode usar pontos para:
     - Descontos em agendamentos
     - Serviços grátis
     - Produtos do salão

3. **Configurar regras de pontuação:**
   - Acesse configuração
   - Defina:
     - Pontos por real gasto (padrão: 1)
     - Bônus por nivel
     - Valores de resgate

### Fila de Espera (Waitlist)

1. **Acesse:**
   - **"Recursos Avançados"** → **"Fila de Espera"**

2. **Como usar:**

   **A) Adicionar cliente à fila:**
   - Cliente pede pra entrar na fila
   - Clique em "+ Adicionar à Fila"
   - Preencha:
     - Nome do cliente
     - Telefone
     - Serviço desejado
     - Preferência de profissional
     - Prioridade:
       - Normal (default)
       - Alta (cliente VIP)
       - Urgente (atendente esperando há muito tempo)

   **B) Acompanhar fila:**
   - Lista ordenada por prioridade e hora de entrada
   - Tempo estimado de espera em tempo real
   - Ações disponíveis:
     - **Chamar:** Quando horário abriu → envia WhatsApp
     - **Adiar:** Cliente não pode mais
     - **Cancelar:** Cliente não veio
     - **Agendar:** Vira agendamento oficial

   **C) Notificações automáticas:**
   - Sistema avisa quando:
     - Seu lugar está chegando
     - Horário abriu
     - Profissional disponível

### Programa de Indicações (Referral)

1. **Acesse:**
   - **"Recursos Avançados"** → **"Indicações"**

2. **Cada cliente tem um código único:**
   - Exemplo: "juan-silva-123"

3. **Como os clientes indicam:**

   **A) Pelo perfil:**
   - Cliente vai no site → "Minha conta" → "Indicar amigos"
   - Vê código único
   - Opções de compartilhar:
     - WhatsApp (botão direto)
     - Copiar código
     - QR Code (mostra para escanear)

   **B) Quando alguém usa o código:**
   - Amigo faz cadastro
   - Insere código no momento do cadastro
   - Sistema registra indicação

4. **Recompensas:**
   - **Quem indica** ganha:
     - R$10 de crédito na conta SysHair
     - 500 pontos de fidelidade
   - **Quem é indicado** ganha:
     - Primeiro agendamento com 15% OFF
     - 5% OFF em todos os agendamentos por 3 meses

5. **Ranking de indicadores:**
   - Lista do mês com quem mais indicou
   - Top 10
   - Premiação especial para top 3

### Lookbook (Galeria Visual)

1. **Acesse:**
   - **"Recursos Avançados"** → **"Lookbook"**

2. **Criar entrada no portfólio:**
   - Click em "+ Nova Entrada"
   - Preencha:
     - Before (Foto antes): Upload
     - After (Foto depois): Upload
     - Serviço realizado
     - Profissional que fez
     - Cliente (opcional - pode ser anonimizado)
     - Descrição / Legenda
     - Tags (ex: "corte", "barba", "coloracao")
     - Visibilidade: Pública (na página do salão) ou Privada

3. **Visualizar portfólio:**
   - Slider Before/After muito suave
   - Filtro por categoria
   - Filtro por profissional
   - Botão "Agendar este serviço" leva direto ao agendamento

4. **Compartilhar nas redes:**
   - Clique em "Compartilhar"
   - Opções:
     - Instagram (com imagem)
     - Facebook
     - WhatsApp (envia link)

5. **Integração com Facebook/Instagram:**
   - Lookbook pode ser integrado diretamente
   - Posta automaticamente nas redes
   - Aumenta alcance orgânico

### Metas (OKRs)

1. **Acesse:**
   - **"Recursos Avançados"** → **"Metas"**

2. **Criar nova meta:**
   - Click em "+ Nova Meta"
   - Preencha:
     - Título da meta
     - Descrição detalhada
     - **Tipo de meta:**
       - Receita mensal
       - Número de agendamentos
       - Novos clientes
       - Taxa de ocupação
       - Satisfação (média de avaliações)
     - **Valor alvo:**
       - Ex: R$30.000 mensais
       - Ex: 200 agendamentos/mês
     - **Data final:** Quando quer alcançar
     - Responsável (professional or salão)

3. **Acompanhar progresso:**
   - Barra de progresso visual
   - Indicador de status:
     - 🟢 No prazo (vai ser alcançado)
     - 🟡 Atenção (precisa acelerar)
     - 🔴 Atrasado (precisa urgência)
   - Atualização automática em tempo real

4. **Histórico:**
   - Metas alcançadas
   - Metas perdidas
   - Aprendizados

## 9. Marketing e Promoções

### Criar Cupons de Desconto

1. **Acesse:**
   - **"Cupons"** no menu lateral

2. **Clique em "+ Criar Cupom"**

3. **Preencha:**

   **A) Código:**
   - Ex: "PRIMEIRA25" (15 caracteres máximo)
   - Deve ser único
  
   **B) Tipo de desconto:**
   - **Percentual:** Ex: 25% OFF
   - **Valor fixo:** Ex: R$20 OFF
  
   **C) Valor:**
   - Se percentual: 25
   - Se fixo: 20.00
  
   **D) Restrições:**
   - **Mínimo de compra:** Ex: R$50 (cupom válido acima deste valor)
   - **Uso máximo:** Ex: 100 (só pode ser usado 100 vezes no total)
   - **Válido de:** Data inicial
   - **Válido até:** Data final
   - **Apenas novos clientes?** Checkbox
   - **Aplica a:** Todos serviços, ou apenas selecionados
  
   **E) Status:**
   - ✅ Ativo (pode ser usado)
   - ❌ Inativo (não aparece para clientes)

4. **Clique em "Salvar"**

### Criar Pacotes de Serviços

1. **Acesse:**
   - **"Pacotes"** no menu lateral

2. **Clique em "+ Criar Pacote"**

3. **Preencha:**

   **A) Nome do pacote:**
   - Ex: "Kit Barba Completa"
   - Ex: "Pacote Beleza Feminina (5 sessões)"
   
   **B) Serviço base:**
   - Qual serviço será vendido no pacote
   
   **C) Quantidade:**
   - Ex: 5 sessões
   
   **D) Preço:**
   - Preço do pacote (com desconto)
   - Ex: 5 x R$50 = R$250, mas você cobra R$200 no pacote

   **E) Desconto:**
   - Calcula automaticamente
   - Mostra % de economia vs comprar individual

   **F) Validade:**
   - Dias que o pacote é válido
   - Ex: 60 dias (cliente tem 2 meses pra usar)

   **G) Descrição:**
   - Detalhes do pacote
   - O que inclui, como funciona

4. **Vender pacote:**
   - Cliente compra no checkout
   - Você recebe pagamento
   - Cliente ganha créditos
   - Cada agendamento usa 1 crédito do pacote

5. **Acompanhar vendas de pacotes:**
   - Aba "Vendas"
   - Ver quanto vendeu de pacotes no período
   - Receita adicional

### Importar Contatos

1. **Acesse:**
   - **"Importar Contatos"** no menu lateral

2. **Como funciona:**

   **A) De outras plataformas:**
   - Excel (cliente lista)
   - CSV
   - Contato do celular
   - Instagram (seguidores)

   **B) Upload do arquivo:**
   - Formato aceito: .xlsx, .csv
   - Colunas esperadas: Nome, Email, Telefone (opcional)

   **C) Mapeamento:**
   - Sistema lê arquivo
   - Você mapeia quais colunas sãoNome, Email, etc.
   - Click em "Importar"

   **D) Resultados:**
   - Total importado
   - Já cadastrados (duplicados ignorados)
   - Novos clientes

3. **Após importar:**
   - Envie campanha de WhatsApp para todos
   - Ofereça cupom de desconto para primeira visita

### Mensagens em Massa (Broadcast)

1. **Acesse:**
   - **"Broadcast"** no menu lateral

2. **Criar nova mensagem:**

   **A) Público alvo:**
   - **Todos os clientes** (base inteira)
   - **Segmento específico:**
     - Visitou nos últimos 30 dias
     - Não visita há 60+ dias
     - Próximos aniversários
     - De tal nível de fidelidade

   **B) Canal:**
   - WhatsApp (usando API Evolution)
   - Push notification
   - Email (em desenvolvimento)

   **C) Mensagem:**
   - Título
   - Texto completo
   - Variáveis:
     - {{Nome do cliente}}
     - {{Nome do salão}}
     - {{Data}}
     - etc.

   **D) Agendar ou enviar agora:**
   - Enviar agora → dispara imediatamente
   - Agendar → define data/hora específica

3. **Exemplos de broadcast:**

   **A) Promoção:**
   ```
   Olá {{Nome}}! 💇‍♂️
   
   Na semana do dia {{Data}} temos promoção especial:
   ☑️ Corte com desconto de 20%
   
   Agende agora: /agendar/barbeariadasjoao
   
   Ou via WhatsApp: (seu número)
   ```

   **B) Aviso de indisponibilidade:**
   ```
   Atenção! 🚨
   
   No dia {{Data}} estaremos fechados para reforma.
   
   Pedimos desculpas pelo inconveniente e agradecemos a compreensão!
   
   Equipe Barbearia {{Nome do Salão}}
   ```

4. **Acompanhar:**
   - Quantos enviados
   - Quantos receberam
   - Taxa de abertura
   - Taxa de cliques

## 10. Configuração do WhatsApp

### Criar Conta na API Evolution

## 13. Para Clientes

### Como Agendar

**Opção 1: Pelo Site/APP**

1. **Acesse:**
   - Site do salão `/agendar/barbeariadasjoao`
   - Ou pelo PWA instalado

2. **Não precisa ter conta para agendar**
   - Pode criar no momento

3. **Passo a passo:**

   **A) Passo 1: Selecionar serviço**
   - Cards visuais com fotos
   - Veja: Nome, Duração, Preço
   - Clique em um serviço

   **B) Passo 2: Selecionar profissional (opcional)**
   - "Sem preferência" = primeiro disponível
   - Ou escolha um específico
   - Veja: Foto, Especialidade, Rating (4.9 ⭐)
   - Status: Disponível/Ocupado

   **C) Passo 3: Data e horário**
   - Calendário visual
   - Destaque de dias disponíveis (verde)
   - Grade de horários (08:00 - 19:00)
   - Horários indisponíveis marcados em vermelho

   **D) Passo 4: Dados do cliente**
   - Se tiver conta: preenche automaticamente
   - Se não: criar cadastro
     - Nome
     - Telefone
     - Email (opcional)
     - Data aniversário (opcional - para promoções)

   **E) Passo 5: Pagamento (opcional)**
   - Opção: Pagar agora (5% de desconto)
   - Ou pagar no salão (normal)
   - Pagar via:
     - Mercado Pago (Pix, cartão, boleto)
     - Usar pontos de fidelidade (se tiver)
     - Usar pacote (se tiver créditos)

   **F) Passo 6: Confirmação**
   - Revisão: Serviço, Profissional, Data, Horário, Preço
   - Clique em "Confirmar Agendamento"

   **G) Confirmação via WhatsApp**
   - Sistema envia mensagem automática
   - Com todos os detalhes
   - Lembrete: 1h antes do horário

**Opção 2: Pelo WhatsApp do Salão**

1. **Se cliente já está cadastrado:**
   - Envia mensagem no WhatsApp do salão
   - Explica qual serviço, qual dia, qual profissional
   - Dono do salão agenda pela dashboard e confirma

2. **Se não cadastrado:**
   - Dono pede para acessar o link do site
   - Ou agenda como convidado

**Opção 3: No Salão (Walk-in)**

1. **Cliente chega sem agendamento:**
   - Dono consulta horário
   - Se tiver vaga, agenda imediatamente
   - Se não, coloca na fila (waitlist)

### Área do Cliente

1. **Login no site/APP:**
   - Email/Password
   - Lembrou? → Entrar

2. **Área do cliente:**
   - **"Meu Perfil"** → Dados pessoais

   - Ver data e hora
   - Reagendar (se ≥24h de antecedência)

## 14. Dicas e Boas Práticas

### Organize sua Agenda

1. **Bloqueie horários de indisponibilidade:**
   - Reuniões pessoais
   - Feriados
   - Férias
   - Ajuste no calendário do profissional

2. **Use cores para identificar tipos:**
   - Cortes em azul
   - Coloração em rosa
   - Pacote em verde
   - Em desenvolvimento

3. **Adicione notas importantes:**
   - Alergias de cliente
   - Preferências de corte
   - Histórico de produtos usados

### Aumente sua Taxa de Ocupação

1. **Ofereça desconto para horários vazios:**
   - Segundas manhãs = 20% OFF
   - Use cupons: "SEGUNDA20"

2. **Use a fila de espera:**
   - Encha buracos na agenda
   - Avisar 30 min antes de liberar horário
   - Prender cliente

3. **Crie pacotes:**
   - Incentiva retorno regular
   - Adianta pagamento
   - Garante fluxo de caixa

4. **Lembre clientes que não vêm:**
   - Sistema alerta: "60 dias sem agendar"
   - Envie promoção via WhatsApp
   - "Volte e ganhe desconto!"

### Use as Funcionalidades de Marketing

1. **Envie broadcast em aniversários:**
   - Use campos de aniversário
   - Mensagem personalizada
   - Ofereça desconto

2. **Use o programa de fidelidade:**
   - Cliente pode resgatar pontos
   - Mais agendamentos repetidos
   - Aumenta LTV (Lifetime Value)

3. **Compartilhe o portfólio:**
   - Posta no Instagram
   - Posta no Facebook
   - Link pode agendar direto

4. **Use o sistema de indicações:**
   - Dê desconto para quem indica
   - Dê desconto para quem é indicado

### Proteja seu Negócio

1. **Exija cadastro:**
   - Evita agendar e não aparecer
   - Pode cobrar no-show
   - Dados de contato

2. **Use pagamento antecipado:**
   - Clientes novos → pedir pagamento com desconto
   - Reduz no-show
   - Garante pagamento

3. **Histórico do cliente:**
   - Registra todos detalhes
   - Evita problemas com pagamento
   - Comprova legal

4. **Backup do WhatsApp:**
   - Conversas com confirmações
   - Comprovações de agendamento
   - Histórico com clientes

### Use a Inteligência Artificial

1. **Analise riscos de churn:**
   - Aja antes do cliente sair
   - Envie promoção
   - Entre em contato

2. **Use cross-sell:**
   - Ofereça serviços complementares
   - "Adicione barba ao corte"
   - Aumenta ticket médio

3. **Defina metas realistas:**
   - Baseie-se em histórico da IA

## 15. Problemas Comuns e Soluções

### Problema 1: Agendamento Não Aparece na Agenda

**Causas:**
- Não clicou em "Confirmar"
- Erro na seleção de data/hora
- Problema de conexão

**Soluções:**
1. Verifique se está em "Pendentes" ou confirmou
2. Tentar agendar de novo
3. Limpar cache e recarregar página

### Problema 2: WhatsApp Não Envia Mensagem

**Causas:**
- API Evolution desconectada
- API Key ou instance ID errados
- Número formatado incorretamente

**Soluções:**
1. Verificar status da API no dashboard Evolution
2. Recriar API Key no Evolution
3. Formato correto: 5511999998888 (com 55, com DDD, sem traços)

### Problema 3: Pagamento Não Passou

**Causas:**
- Cartão recusado
- Insuficiente saldo
- Erro de conexão Mercado Pago

**Soluções:**
1. Cliente: Verificar com banco
2. Tentar outro método de pagamento
3. Verificar logs de webhook

### Problema 4: Ocupação de Horário Errada

**Causas:**
- Configuração de horário do profissional incorreta
- Timezone do servidor diferente do salão

**Soluções:**
1. Verificar horário de abertura/fechamento do salão
2. Verificar horário do profissional
3. Ajustar timezone na configuração

### Problema 5: Dashboard Não Mostra Dados

**Causas:**
- Permissões de usuário
- Data incorreta no filtro
- Cache antigo

**Soluções:**
1. Verificar que usuário é "admin"
2. Ajustar data/periodo no filtro
3. Limpar localStorage e recarregar

### Problema 6: Trial Expirou Mas Pode Usar Sistema

**Causas:**
- Status da subscription não atualizado
- Webhook do Mercado Pago não funcionou

**Soluções:**
1. Verificar no dashboard do Mercado Pago
2. Atualizar status manualmente no Super Admin
3. Usar `/super-admin` para fixar

### Problema 7: Não Consigo Instalar PWA

**Causas:**
- Navegador não suporta
- Protocolo não é HTTPS (obrigatório)
- Ainda não interagiu o suficiente

**Soluções:**
1. Usar Chrome ou Edge (melhor suporte)
2. Certificar ser HTTPS
3. Navegar por todo site primeiro
4. Prompt aparece depois de interagir

### Problema 8: Push Notifications Não Chegam

**Causas:**
- Permissão negada
- Service worker não registrado
- Firebase Cloud Messaging não configurado

**Soluções:**
1. Verificar permissão nas configurações do navegador
2. Verificar se service worker está ativo
3. Recarregar subscription no Supabase
